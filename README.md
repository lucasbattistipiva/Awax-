# Awax - Landing Page Responsiva

Uma landing page moderna desenvolvida com **HTML5** e **CSS3**, baseada no layout Awax. O projeto foi criado com foco em boas práticas de estruturação, organização de código e responsividade.


---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox
- Media Queries
- Google Fonts (Montserrat)

---

## ✨ Funcionalidades

- Header com menu de navegação
- Banner principal (Hero Section)
- Seção "About Us"
- Seção de Serviços
- Galeria de Projetos
- Equipe
- Depoimentos de Clientes
- Empresas Parceiras
- Planos e Preços
- Recursos Premium
- Estatísticas da Empresa
- Redes Sociais
- Formulário de Contato
- Localização (Mapa)
- Rodapé completo
- Layout totalmente responsivo

---

## 📱 Responsividade

O projeto foi desenvolvido para diferentes tamanhos de tela, possuindo adaptações para:

- 💻 Desktop
- 📱 Smartphones
- 📲 Tablets

Utilizando Media Queries para melhorar a experiência do usuário.
